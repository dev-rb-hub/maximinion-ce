# MaxiMinion for VS Code

Sanitize the active editor document locally and review the result in a new, unsaved editor. The source document is never modified.

Use **MaxiMinion: Sanitize Active File** to open a sanitized preview, or **MaxiMinion: Copy Sanitized Active File** to copy sanitized text to the clipboard. The extension does not send file contents to a service.

Secret detection is pattern-based and cannot guarantee that every sensitive value is found. Review the output before sharing it.
